# 🎮 Tic Tac Toe Game using HTML, CSS, and JavaScript

A fun and interactive 2-player Tic Tac Toe game built with **vanilla JavaScript**, styled with **CSS**, and structured with **HTML**. It includes win and tie detection, player turn indicators, and a reset button to start a new game.

---

## 🚀 Features

- ✅ Two-player gameplay (X and O)
- ✅ Win and tie condition check
- ✅ Alert for win or tie
- ✅ Stylish responsive layout
- ✅ Restart game button

## 🧠 How To Play

1. Player 1 uses `X` and Player 2 uses `O`.
2. Click on empty cells to make a move.
3. First to complete a row, column, or diagonal wins!
4. If all cells are filled without a winner, it's a tie.
5. Click the **Restart** button to play again.
